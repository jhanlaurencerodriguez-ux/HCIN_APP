About
HCIN reads and writes through your existing Apps Script backend — the same one your Telegram bot uses. Google Sheets stays the live source of truth and can still be edited directly at any time.
Notifications
HCIN can notify you when today's classes or events start, while the app is open or running in a tab. It can't notify you if your phone is locked or the app is fully closed — that's a real limitation of web apps, not a setting. For anything you can't miss, also set a reminder in your phone's own clock or calendar.
Face ID / Touch ID lock
Require Face ID or Touch ID to open HCIN on this device. This is device-only — it doesn't sync, and it doesn't replace your API secret as the real security boundary. If you lose access to Face ID on this device, reconnect using your setup link to get back in.
